# 交付说明

第九届浙江省大学生网络与信息安全竞赛，作品挑战赛。

## 一、交付物

`BlueWhiteAgent.exe`，约 1.4 MB。双击即用，不需要安装。

- 界面、默认检测规则、图标全编在 exe 里，边上不需要再放任何目录或文件
- 只用 Windows 自带组件：WinHTTP、bcrypt、系统 UCRT。不用装 Python，不用装 Node，也不用装运行库
- 运行数据落在 `C:\Users\<用户名>\.bw_agent`。exe 放桌面、U 盘、下载目录都行

## 二、上手三步

1. 双击 `BlueWhiteAgent.exe`。这是界面程序，不会弹命令行窗口
2. 等一两秒，界面窗口自动打开。点右上角「设置授权」，把目标主机加进授权池并勾选授权。站点不在 80 或 443 端口就写成 `域名:端口`，例如 `127.0.0.1:8081`。可以批量粘贴，前面加 `!` 表示不允许，例如 `!exp.com/admin/`
3. 在输入框里直接说要做的事

```
把这个站完整巡检一遍      工作台会实时显示它每一步在想什么、做了什么、看到什么
复测一下                 看发现状态推进：已修复、仍未修复、判不了
出报告                   看报告与告警页的分级统计和推送
核对证据                 看证据与闭环页：每条结论的证据、状态与缺证据清单
```

关掉界面窗口就是退出程序，后台服务随之停止，端口自动释放。`--debug` 调试时例外：窗口关掉后服务继续跑，方便反复打开界面看结果，结束时关掉命令行窗口或按 `Ctrl+C`。

要看命令行窗口和实时日志，加 `--debug` 启动。不带 `--debug` 时日志写在 `C:\Users\<用户名>\.bw_agent\agent.log`。

## 三、第一次运行

界面是本程序自己的 WebView2 窗口，Chromium 内核，随系统 Edge 提供。加载器 `WebView2Loader.dll` 已编进 exe，不会在程序旁边多出文件。运行时目录由程序自己找，有些机器上只登记在 32 位注册表视图里，加载器按常规方式找不到。万一这台机器没有 WebView2 运行时，程序会自动退回系统 Edge 的 `--app` 窗口，界面照样能开。原生 Win32 窗口那套实现已经移除，一套界面只维护一份。

首次运行自动生成数据目录 `C:\Users\<用户名>\.bw_agent`，里面有 `rules\`（六个域各一个文件，改它就能改检测范围，不用重新编译）和 `skills\` 下每个内置技能的说明。起始数据是空的，跑一次巡检就有内容。界面窗口的浏览器数据放在这里的 `webview2\`，退回 `--app` 时是 `ui-profile\`，不会往程序旁边写任何东西，所以程序目录可以是只读的。

## 四、可选：接大模型

不接模型时对话不能用。发一句自然语言，程序会如实回复模型不可用并停下；界面上的数据视图、`/` 命令（例如 `/recon 目标地址`）和命令行照常工作，只是少了「自己判断下一步查什么」这一层。

要接就在界面「设置 → 模型 → ＋ 接入一家」里选协议（OpenAI 兼容、Anthropic、恒脑开放服务），填地址和密钥，点「保存并测试」，通没通当场就知道。可以接多家，自己选一条当前在用，程序不会自动切换。调不通时这一轮会停下来把原因写清楚，不用规则凑结论。

包里不含任何厂商的密钥。老部署可以继续用 `.env`，放在 exe 旁边，照根目录的 `.env.example` 填，首次启动自动转成 `models.json` 里的一条，不用重新填。

## 五、可选：加新能力（不用重新编译）

首次运行会把内置技能的说明导出到数据目录 `skills\skill_*.md`。这些不是示例文件，而是「能力清单」页里那些技能的真身说明，按本单位口径改文字就生效。

| 位置 | 是什么 | 怎么用 |
|---|---|---|
| `skills\skill_*.md` | 内置技能说明：何时用、解决什么、用到哪些工具 | 直接改文字，重启程序即采用；删掉就回到出厂说明 |
| `skills\我的技能.md` | 自己新增技能，Markdown 写什么时候用、分几步做 | 新建文件即可，模型会当方法论照着做 |
| `tools\<名字>.json` | 外部工具：声明参数加一条命令，stdout 就是结果 | 新建文件即可，重启后出现在能力清单，标「外部工具」 |
| `mcp.json` | MCP 服务器：填启动命令，stdio 与 JSON-RPC 2.0 | 新建文件即可，工具以 `mcp__服务器名__工具名` 出现 |

命令参数会被转义，超时会中止，输出过长会截断。外部能力必须在文件里显式写 `allow: true` 才会执行，从别处拷来的配置不会自己跑起来。各文件格式见 [README.md](../README.md) 第 3 节，也可以在界面「设置 → 技能 / 工具」里直接改文件。

命令行里也能单独试：

```bat
BlueWhiteAgent.exe tools                        :: 列出全部能力，外部与 MCP 会标出来
BlueWhiteAgent.exe run skill_recon              :: 单独跑一个技能
```

## 六、源码与工程目录

程序本体在 `Agent-Zero\` 下，细节见 [README.md](../README.md)。

| 目录 | 内容 |
|---|---|
| `Agent-Zero\src\main\` | C++20 源码约 2.3 万行：决策循环、技能、工具、规则层、取数通道、落盘、自写 HTTP 与 SSE |
| `Agent-Zero\src\tools\` | 工具实现，一个工具一个 `.cpp` |
| `Agent-Zero\ui\` | 界面源码：index.html、app.css、app.js、图标。改完重跑 `build.bat` 即编进 exe |
| `Agent-Zero\build\` | 构建产物。`BlueWhiteAgent.exe` 是交付物，`agent.exe` 是同源副本 |
| `Agent-Zero\data\` | 出厂数据：`rules\`（六个域）、`skills\<名字>\SKILL.md`、`tools\bw_tools\`（工具声明）、`mcp.json`、WebView2 加载器 |
| `Agent-Zero\tools\` | 构建期小工具：`mkres.cpp` 打包资源，`gen_webview2_min.js` 生成 WebView2 接口声明 |

配套靶场在 [03_演示环境/靶机服务器](../03_演示环境/靶机服务器)，独立于作品本体，只用于演示与评测。

[README.md](../README.md) 是完整说明：运行方式、可扩展能力、规则、合规边界、数据落盘、界面、验收步骤、已知边界。内部设计与演示怎么跑，另见 [系统架构](../01_系统架构/系统架构.md)、[工具清单](../02_工具清单/工具清单.md)、[演示环境](../03_演示环境/演示环境.md)、[测试报告](../05_测试报告/测试报告.md)。

## 七、构建

```
Agent-Zero\build.bat            发布版
Agent-Zero\build.bat debug      调试版，带 selftest
```

构建需要 MinGW-w64 的 g++，支持 C++20。产物落在 `Agent-Zero\build\`。构建期把界面三件套、图标、出厂规则和 WebView2 加载器转成 C++ 数组编进 exe，所以运行时不依赖程序目录里的文件。

## 八、合规边界

这些约束写在程序里，不是写在文档里。

- 只对授权池内的主机发请求。池外请求在取数通道就被拦下，并让整轮巡检立刻停止。池里的 `!` 条目可以精确排除某个路径，例如 `!exp.com/admin/`
- 只做只读检查，仅发 `GET`、`HEAD`、`OPTIONS`，不写入、不上传、不爆破、不利用
- 默认 2 请求每秒。每次请求都写进 `audit.jsonl`；证据里的手机号、身份证、邮箱、IP、银行卡、凭据在落盘前打码
- 工具调用前有权限审批。默认「询问」逐条问，「全部允许」需先看一次警告，也可以按工具名自定义允许、询问、拒绝并存成预设
- 界面服务只绑 `127.0.0.1`，静态资源白名单，路径穿越直接返回 404
