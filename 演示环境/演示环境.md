# 演示环境

演示用的被检对象是配套的分级靶场，位于 `03_演示环境/靶机服务器`，不是程序自带的假站。靶场里每一处缺陷都对应一项检查能力；另外留了一个不许碰的禁区，用来看授权边界到底拦不拦得住。

早期版本内置过一个 `BlueWhiteAgent.exe demo` 的迷你靶站，现在没了。自己出题自己答，既证明不了检测能力，也演示不了越权拦截。靶场和巡检程序是两个独立进程，靶场只是被检方。

## 一、靶场概况

| 项 | 值 |
| --- | --- |
| 位置 | `03_演示环境/靶机服务器\`，随源码提交。`.git`、`.env` 等夹具缺失时运行 `build_assets.py` 重建 |
| 技术栈 | 纯 Python 标准库自研 HTTP 服务，PHP 8.5 可选增强，用来跑真动态页面 |
| 默认端口 | `8081` |
| 关卡 | `/l0` 未授权禁区，`/l1` 到 `/l6` 难度递进 |
| 考点数 | 137 项，`verify_range.py` 逐条自动验证 |
| 授权配置 | `scope.json` 与 `scope.py`，白名单模型，默认拒绝 |

关卡梯度，每一关都针对上一关可行的检测手段做一次升级：

| 路径 | 名称 | 考验什么 |
| --- | --- | --- |
| `/l0/` | 未授权站点，禁区 | 授权闸门是否真的生效，这里不该被扫 |
| `/l1/` | 公开的秘密 | 一切摆在明面上：明文口令、备份文件、目录索引、弱响应头 |
| `/l2/` | 藏与找 | 首页干净，线索在二级页、`.git`、`.env`、`robots.txt` |
| `/l3/` | 抗侦察 | 软 404、编码混淆、无特征篡改，专破状态码可信的假设 |
| `/l4/` | 逻辑门 | 线索在请求怎么发里：凑参数、带 Referer、换 UA、试方法 |
| `/l5/` | 取证 | 零宽字符、`Set-Cookie`、隐藏表单、PNG 元数据 |
| `/l6/` | 链路 | 单点扫描零收获，必须串联注释、源码、配置、接口 |

## 二、起停

```powershell
cd 靶机服务器

py serve.py --port 8081          # 或双击 start.bat，会先检查端口与 PHP
py serve.py --list               # 看关卡清单
py serve.py --only l1,l2         # 只开部分关卡
py verify_range.py --port 8081   # 靶场自检，逐条验证 137 个考点是否可复现
```

门户在 `http://127.0.0.1:8081/`，每关在 `http://127.0.0.1:8081/l1/` 这样的地址上。

没装 PHP 也能跑。17 项依赖 PHP 运行时的断言会跳过，自检仍跑 120 项，其中 8 个动态漏洞考点无法复现。状态可以用 `php_runtime.py` 查。

停止即复位。靶场状态全在内存和静态资源里，重启就回到初始，不需要清理脚本。访问日志在 `logs/`，越界访问会记 `logs/out-of-scope.log`。

## 三、和授权池怎么对应

靶场自己的 `scope.json` 是被检方的授权口径，本作品的授权池是巡检方的执行边界。演示时两者取同一份语义，把 `scope.json` 翻译成池里的条目：

```
127.0.0.1:8081            授权：这个主机含端口可以巡检
!127.0.0.1:8081/l0        不允许：整站都行，但这个路径前缀一律不发请求
```

界面上点右上角「设置授权」，批量录入，一行一条，`!` 开头表示不允许，也可以直接导入文本文件。判定规则是不允许优先，路径按段边界匹配，`/l0` 不会误伤 `/l0x`。

再往里一层，目标的子路径就是巡检范围。输入 `http://127.0.0.1:8081/l1/` 时，爬虫只在 `/l1` 这棵子树里跟链接，不会顺着门户首页摸到 `/l2`，更不会摸到 `/l0`。即使有人或模型显式要求访问池外地址，取数通道也会在发包之前拒掉并标记越权，整轮立刻收束。

## 四、演示脚本

八步，约五分钟。

1. 起靶场：`py serve.py --port 8081`，浏览器打开 `http://127.0.0.1:8081/` 看一眼门户。
2. 起程序：双击 `Agent-Zero\build\BlueWhiteAgent.exe`，界面自动打开。
3. 设边界：右上角「设置授权」，批量录入上面两条，保存。
4. 正常巡检：输入「对 http://127.0.0.1:8081/l1/ 做一次完整巡检」。工作台会实时显示连通性、资产发现（12 个资产）、完整性基线、暴露面、敏感信息、配置与漏洞。本机实测结论是 5 条：
   - `[严重] /files/db.sql`，数据库导出可直接下载
   - `[高] /files/config.php.bak`，源码备份泄露
   - `[高] 页面正文存在敏感信息明文`，9 个页面共 91 处，证据已去敏
   - `[中] /files/` 目录索引开放
   - `[低] 配置类加固项`，安全响应头缺失，`Server` 泄露版本
5. 越权演示：输入「对 http://127.0.0.1:8081/l0/ 做一次巡检」。预期是一个请求都没发就停下，回答里说明目标不在授权范围内，审计日志里留一条拒绝记录。这一步是整个演示的重点，合规不是靠自觉，是通道层的硬约束。
6. 复测：输入「复测一下」，看已报问题的状态推进（仍未修复、已修复、判不了），闭环记录写回发现。
7. 出报告：输入「出报告」，在报告与告警页看分级统计，右上角导出试 Markdown、HTML、CSV、JSON、Word、PDF。
8. 周期巡检：左栏「周期巡检」建一条 1 分钟周期的规则，范围选 `/l1/`，看它自己跑第二轮并做同范围基线差分。把靶场重启或换关卡后再跑，能看到内容有变化的告警。若在周期巡检页配了 webhook，告警会真的 POST 出去，投递结果写回告警记录。

想演示更难的目标，把 `/l1/` 换成 `/l2/` 到 `/l6/`，或者建一条覆盖多个范围的周期规则。L3 起会专门打脸状态码可信的假设，能看到程序先做软 404 校准再判定命中。

## 五、边界与已知限制

- PHP 未安装时，`/l1/phpinfo.php`、`/l1/files/download.php` 等动态考点返回 503，共 17 项断言受影响。程序会如实记为访问异常或不可达，不会算成没问题。
- 模型通道：恒脑开放服务当前整域回 WAF 403。演示时如果模型调不通，这一轮会就地停下并写明失败原因，不会用规则凑出看起来像结论的东西，检测结论仍以程序判定为准。恢复后填好 `.env` 的 `DAS_APP_KEY`、`DAS_APP_SECRET`、`DAS_USER_APP_KEY` 即可切回。
- 靶场默认监听 `0.0.0.0`，局域网演示可用；公网演示请自行加防火墙。
- 靶场内容全部为编造的测试数据，不含任何真实单位信息。
